# Silhouette Photo Mode UI Test 11

## 日本語

Test 11 は、完成候補のTest 10を残したまま比較できる、別デザインの起動アイコン版です。

- 起動ボタンの枠サイズとクリック範囲はTest 10と同じ
- 白い正方形を左上の黒と右下の白へ斜めに二分
- 中央の円は背景と逆の白黒で二分し、シルエット／反転を表現
- OFF時は白黒、ON時はオレンジ枠と右上の点灯ランプを表示
- 同じアイコンをもう一度押すと専用小窓を閉じる
- シルエット描画、色設定、ホットキー、INI形式には変更なし

### 導入

1. 正式版 v1.0.1 は有効のままにします。
2. Test 10を含む以前のシルエットTestパッケージを無効にします。
3. このZIPをMO2で導入し、正式版 v1.0.1 より後へ配置します。
4. 既存INIは削除しないでください。

### 比較項目

- Test 10の丸い人物アイコンと、Test 11の反転円アイコンのどちらが直感的か
- 横のホットキーボタンと高さが揃って見えるか
- 小さい表示でも斜めの白黒と中央円を識別できるか
- OFF時と、オレンジ枠・点灯ランプが出るON時を区別できるか
- 同じアイコンで小窓を開閉できるか

## English

Test 11 is an alternate launcher icon build intended for direct comparison with the retained Test 10 candidate.

- Keeps the Test 10 button frame size and click target
- Splits a white square diagonally into black upper-left and white lower-right halves
- Splits the center circle into opposite colors to suggest silhouette/inversion
- Keeps OFF black/white and ON indicated by an orange border and upper-right lamp
- Pressing the same icon again closes the dedicated settings window
- No changes to silhouette rendering, colors, hotkeys, or the INI format

### Installation

1. Keep official v1.0.1 enabled.
2. Disable Test 10 and every earlier silhouette test package.
3. Install this ZIP with MO2 and place it after official v1.0.1.
4. Do not delete the existing INI.
