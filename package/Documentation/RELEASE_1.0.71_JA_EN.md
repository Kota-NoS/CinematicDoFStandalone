# CinematicDoFStandalone 1.0.71

## 日本語

1.0.71は、実ゲームでの追加調整を組み込み初期値へ反映するプリセット更新版です。機能、INI形式、プリセットの内部IDは1.0.7から変更していません。

- プリセット8「光条」：明部抽出を広げ、回折光条を強めつつ、絞り形状と広域フレア抑制を再調整しました。
- プリセット10「カスタム2」：手前のピント範囲と手前ぼかしを追加しました。
- 既存INIはそのまま利用できます。

新しい初期値を使う場合は`Full-MO2`版を導入してください。現在の設定を保持したままDLLのみ更新する場合は、INIを含まない`Update-Merge-MO2`版を既存MODへMergeしてください。

## English

Version 1.0.71 updates the bundled preset defaults after additional in-game tuning. Features, the INI schema, and stable preset IDs are unchanged from 1.0.7.

- Preset 8, Starburst: broadens highlight extraction, strengthens diffraction rays, and retunes the aperture shape and wide-flare suppression.
- Preset 10, Custom 2: adds near-focus range and foreground blur.
- Existing INIs remain compatible.

Install the `Full-MO2` package to use the revised defaults. To update only the DLL while preserving current settings, merge the INI-free `Update-Merge-MO2` package into the existing mod.
