# Filled Aperture Test 2 / 形状ボケ内部補完 Test 2

## 日本語

Test 1で中央が埋まることを確認できたため、Test 2では「最高」の均一さを改善します。

- OFFと「高」はTest 1から変更していません。
- 「最高」はサンプル数の増加に加え、リングごとの角度をずらします。
- 各サンプルを同一半径へ並べず、リング幅の内側へ半径方向にも分散します。
- 通常描画、「髪を馴染ませる」モード1・2へ同じ処理を適用します。

同じ構図と設定で「高／最高」を切り替え、形状ボケ内部の同心円状の濃淡、点や筋、全体の均一さを比較してください。

## English

Test 1 successfully filled the centre. Test 2 improves the visual uniformity of `Highest`.

- Off and High are unchanged from Test 1.
- Highest now rotates each sampling ring in addition to using more samples.
- Samples are also distributed across each ring's radial width instead of sharing one exact radius.
- The same path is used by standard rendering and Blend Hair modes 1 and 2.

Using the same composition and settings, compare High and Highest for concentric brightness bands, visible points or streaks, and overall uniformity inside shaped bokeh.
